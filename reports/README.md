# 연구보고서와 발표자료

## 지금 읽을 수 있는 자료

[최종 연구보고서 PDF](research-report.pdf)는 「목자판 영상의 수위 추정 모델 비교와 최종 오류 분석」입니다. 보고서 표기는 2026년 9월 21일 최종 평가 및 데이터·모델 설명 보강본이며, 24쪽입니다. 작성자는 김태환, 백승우, 신동건, 구승훈입니다.

공개 전 PDF의 본문·링크·메타데이터와 첨부 수식 XML을 점검했고, 개인 인증 자료와 비공개 클라우드 경로는 발견하지 못했습니다. PDF는 원본과 같은 바이트로 보존했습니다. 본문과 연구 그림은 당시 기록이며, 원 데이터 자체를 배포하는 자료는 아닙니다.

결과의 현재 확인 수준과 원시 산출물 확보 여부는 [근거 안내](../docs/evidence.md)에 따로 적었습니다. 보고서에 기록된 결과와 공개 준비 과정에서 직접 실행한 결과 읽기 예제를 구분해 주세요.

## 아직 포함하지 않은 자료

최종 발표용 PDF/PPTX는 현재 로컬에서 확보하지 못했습니다. Figma의 편집 화면과 과거 시안은 최종 제출 파일과 구분했습니다. 실제 최종 발표 파일을 확보한 뒤 이 폴더에 추가할 수 있습니다.

대회 출제문서 원본 PDF는 이 저장소에 재배포하지 않았습니다. 미션의 요지는 [프로젝트 소개](../README.md)와 [수행 과정](../docs/research-process.md)에 설명했습니다.
