## 구분해서 읽을 기록과 빠진 자료

**감사와 분할 사이의 01R이 없습니다.** 분할 노트북은 형식 불일치 처리와 감사 완료 상태를 담은 후속 자료를 입력으로 요구합니다. 최초 감사 노트북의 중단 기록을 최종 감사가 실패했다는 결론으로 바꾸거나, 반대로 빠진 보정 실행까지 공개되었다고 설명하지 않습니다.

**초기 세 CNN 비교의 원시 결과가 없습니다.** 모델 비교 코드에는 세 후보와 실행 모드가 있지만, 현재 저장 출력은 선택된 ConvNeXt의 전체 학습입니다. 보고서의 초기 비교 RMSE와 현재 전체 학습 RMSE를 같은 실험의 행으로 섞지 않았습니다.

**자료 버전 이름과 실행 규모도 구분해야 합니다.** 학습 입력 준비 노트북은 `DATA_PROFILE="full"`이지만 저장 자료 버전 이름에는 `pilot`이 남아 있습니다. 이름만 보고 일부 자료 실행이라고 결론내리지 않고 설정과 실제 행 수를 기준으로 읽습니다.

**ROI 실행 이름이 이어지지 않습니다.** 현재 ROI 노트북의 full 설정은 `full-v1`을 가리키지만 모델 선택 노트북은 `router-full-v2` 결과를 읽습니다. 이 이름들은 실행 산출물을 구별하는 식별자입니다. 차이가 있다는 사실을 남기며, 공개 코드가 최종 선택 당시 코드와 완전히 같다고 주장하지 않습니다.

**재분할의 합성 검사와 실제 자료 실행은 별도입니다.** `synthetic_self_test()`는 작은 합성 자료로 교환 규칙과 수량 유지 등을 확인하며, 저장 출력은 목적함수 26.218660→21.374194와 `accepted_swaps: 9`입니다. 바로 다음 실제 자료 최적화 셀에는 `objective: 20.466860227779286 -> 8.074057890211245`, `accepted swaps: 2736`이 저장되어 있습니다. 실제 자료 실행의 이 수치는 보고서의 20.466860→8.074058와 수락 교환 2,736회에 일치합니다. 보고서의 각 방향 2,611장 이동은 최종 소속을 비교한 수량이므로 교환 수락 횟수와 구분합니다. 원시 분할 목록과 seal 파일은 아직 회수하지 못해 표본별 분할을 독립 재검사하지는 못했습니다.

**초기 모델 평가용 03F는 코드만 회수했습니다.** 원본 작업 자료에서 별도로 찾은 노트북은 출력이 0개입니다. 선택적인 과거 평가 코드로 안내하며, 초기 모델 평가가 해당 파일에서 완료됐다는 근거로 사용하지 않습니다. 초기 모델 RMSE 0.155691 m와 상세 오류 분석은 보고서 기록에서 가져왔습니다.

**모델 가중치와 원시 예측·잔차 파일은 없습니다.** 코드나 출력에 저장 경로가 있어도 해당 파일을 현재 확보한 것과는 다릅니다. 공개 저장소는 원본 데이터와 비공개 test 연결표도 배포하지 않습니다. 최종 발표 자료의 내보낸 파일 역시 확보하지 못했고, Figma 화면 캡처를 최종 발표본으로 대체하지 않았습니다.

## 공개 사본에서 바꾼 것

공개 노트북에는 읽기 쉬운 소개와 탐색 링크를 붙였습니다. 원래 비공개 프로젝트·저장소 식별자는 자리표시자로 바꾸고, 내장 이미지 출력은 제거했습니다. 수치와 표 같은 텍스트 출력은 보존했습니다. 그래서 원래 출력에 있던 사진이나 그래프가 일부 보이지 않을 수 있습니다.

셀의 `execution_count`가 모두 `null`이어도 저장 출력은 존재합니다. 실행 번호만으로 미실행이라고 판단하지 않았으며, 일부 출력이 있다는 사실만으로 모든 단계의 완료를 인정하지도 않았습니다. 각 파일에서 실제 남아 있는 내용만 근거로 삼았습니다.

결과 그래프를 재생성하는 [CPU 노트북](../notebooks/00_read_results.ipynb)은 이 공개 작업을 위해 만든 읽기 도구입니다. 보고서 집계값을 시각화하며, 연구 모델을 다시 평가하는 노트북과 구분됩니다.
